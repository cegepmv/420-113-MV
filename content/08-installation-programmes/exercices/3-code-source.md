1. Installez le paquet `build-essential` en utilisant le gestionnaire de paquets apt (toujours faire une mise à jour de la base de données locale des paquets disponibles avant !)

2. Téléchargez le fichier suivant dans Debian : https://ftp.gnu.org/gnu/aspell/aspell-0.60.8.1.tar.gz

3. Décompressez l’archive avec la commande suivante : `tar xzf aspell-0.60.8.tar.gz`

4. Allez dans le répertoire `aspell-0.60.8/` créé par la commande précédente.

5. Affichez la liste détaillée des fichiers de ce répertoire. Quelles sont les permissions du fichier nommé `configure`?

6. Lisez les instructions d’installation dans le fichier `README` et installez le programme.

7. Testez l’installation en lançant la commande `aspell -v`. 

8. Installez `git` en utilisant `apt` (toujours faire une mise à jour avant d’installer !)

9. Allez sur le projet GitHub suivant : https://github.com/vergoh/vnstat puis clonez le répertoire localement.

10. Essayez d’installer le programme à partir des consignes dans le fichier `INSTALL.md`.
    1. Quel problème apparaît à la commande `./configure`?
    2. Utilisez `apt` pour chercher et installer le paquet manquant, puis poursuivez l’installation.

11. Affichez la version du programme avec la commande `vnstat -`v
