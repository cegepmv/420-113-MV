1. Téléchargez le fichier d’installation de Google Chrome suivant sur votre VM Debian : https://dl.google.com/linux/direct/google-chrome-stable_current_amd64.deb
Dans quel répertoire le fichier .deb a-t-il été téléchargé?

2. Utilisez dpkg pour installer Chrome. 

3. Allez sur le site https://atom.io et le paquet .deb de l’éditeur de texte Atom.

4. Essayez de l’installer avec dpkg. Quel est le message d’erreur? Quelle est la solution selon vous? Réglez le problème et terminez l’installation de Atom.

5. Désinstallez les deux applications de votre système.
